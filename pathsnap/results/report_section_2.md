## 2. Preprocessing and features

We read each trip's GPS track, road nodes, directed arcs, and reference route. GPS observations with a missing field are removed, and the remaining observations are sorted by timestamp. The loader applies the null-row drop defensively; in the current workspace copy, trip 57's raw track contains 1,645 complete rows and no NaN rows, although 25 integer timestamps are absent between 1 and 1,670.

Longitude and latitude are projected to UTM zone 32N so candidate distances and geometric features are expressed in metres. For each trip, the road network is cropped to arcs whose endpoint nodes lie inside the GPS-track bounding box expanded by 300 m. This reduces the network searched for candidates while retaining nearby roads. At each GPS point, arcs within a 60 m distance threshold are candidates. The threshold defines the local search neighbourhood; it can omit observations farther from the mapped network, so we monitor candidate and label misses rather than treating 60 m as guaranteed coverage.

For each point–arc candidate pair, the feature table includes the point index (`pt`), directed arc ID and endpoint node IDs (`arc_id`, `u`, `v`), perpendicular point-to-arc distance (`dist`), fractional position along the segment (`t`), segment length (`alen`), and segment bearing (`abr`). Motion/context features are GPS-derived speed and time gap (`speed`, `gap`), cosine and absolute angular difference between GPS heading and road bearing (`cos_h`, `dh_deg`), number of candidates at that point (`n_cand`), distance rank (`rank`), and distance above the nearest candidate (`d_minus_best`). The binary label `y` marks the nearest candidate arc that appears in the reference route within a forward search of up to 50 route positions; the search proceeds in point order to respect route progression.

The generated training statistics cover 80 trips and 208,417 retained GPS points. Trip 54 has no candidate for 16,183 of 19,313 points (83.8%); trip 21 has no candidate for 691 of 15,783 (4.4%). The label miss rate is also high for trips 6 (38.5%), 26 (38.8%), and 33 (52.5%). These are observed anomalies, and their cause has not been established. The student-test preprocessing summary covers 10 trips and 19,160 points; because this table is generated from the available route files, its route-label miss field is a preprocessing diagnostic, not a claim of official model accuracy.

The source stats and feature tables are in `prep_stats_train.csv`, `prep_stats_student_test.csv`, `feat_train.pkl`, and `feat_student_test.pkl`. The EDA notebook (`notebooks/01_eda.ipynb`) contains the per-split summary, raw-file completeness audit, three-track plot, and interactive GPS/reference-route map.
